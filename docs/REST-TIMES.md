# Default rest times and where they come from

Checked November 1, 2026. All three are editable in the app (15 s steps, 0:15–15:00).

| Set type | Default | Evidence |
|---|---|---|
| **Light** (moderate weight, ~8–15+ reps, reps left in the tank) | **1:30** | Singer et al., 2024 Bayesian meta-analysis: a small hypertrophy benefit for resting **> 60 s**, and no detectable extra benefit beyond **~90 s**. Most participants were untrained, so trained lifters may benefit from a bit more. [Frontiers in Sports and Active Living](https://www.frontiersin.org/articles/10.3389/fspor.2024.1429789/full) |
| **Heavy** (near max, ~1–6 reps) | **3:00** | Schoenfeld et al., 2016: trained men resting **3 min** gained more strength (squat, bench 1RM) than with 1 min. [PubMed 26605807](https://pubmed.ncbi.nlm.nih.gov/26605807/). Review (Sports Medicine, 2009): **3–5 min** produced greater absolute strength gains. [Summary](https://read.qxmd.com/read/19691365/rest-interval-between-sets-in-strength-training) |
| **Failure** (no reps left) | **4:00** | **Estimate, not established.** No study found isolates rest length after failure sets. The 2024 meta-analysis found that failure vs. non-failure didn't change the rest–growth relationship, but failure training does slow short-term recovery. So this is heavy + 1 minute as a practical buffer. Shorten it if you're ready sooner. |

**Rule of thumb:** if you're cutting reps on the next set because you're still gassed, rest longer. The timer has **+15s** for that.
