# Do Not Disturb during workouts

iOS doesn't let any app switch Focus (Do Not Disturb) on or off by itself. The Shortcuts app can. So you create two tiny shortcuts once, and Climb High runs them when a workout starts and ends. The app has the same guide under **Settings → Do Not Disturb → Set it up**.

## 1. The "on" shortcut
1. Open **Shortcuts** → tap **+**.
2. Add the action **Set Focus** → choose **Do Not Disturb** (or **Fitness**) → **Turn On**.
3. Name it exactly **Climb High Focus On**.

## 2. The "off" shortcut
1. **+** → **Set Focus** → same Focus → **Turn Off**.
2. Name it exactly **Climb High Focus Off**.

## 3. Let Climb High's alerts through
iPhone Settings → **Focus** → Do Not Disturb → **Apps** → add **Climb High**.
(Rest *alarms* ring through Focus anyway. This matters if you use **Buzz** mode.)

## 4. Turn it on in the app
Climb High → Settings → **Turn on Focus during workouts**.

When you start a workout, iOS briefly flips to Shortcuts and comes straight back. That's normal; it's how Shortcuts runs.

**Different names?** Change them in Climb High → Settings → Do Not Disturb → Set it up → Shortcut names.

**Bonus (iPhone 17):** put Climb High's "Start Rest Timer" on the **Action Button** (Settings → Action Button → Shortcut) to log a heavy set and start the rest with one press.
